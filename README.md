# बाप्पांच्या आगमनाचा सोहळा | राजेशाही डिजिटल आमंत्रण पत्रिका
### Royal Mobile-First Maharashtrian Ganpati Digital Invitation Website

महाराष्ट्रीयन परंपरेला साजेसा, अत्यंत लोभस, मंगलमय आणि राजेशाही (Royal Minimalist) मोबाइल-फर्स्ट डिजिटल गणेशोत्सव आमंत्रण अनुभव.

---

## 🌸 प्रमुख वैशिष्ट्ये (Key Features)

- **१००% अस्सल मराठी भाषा व देवनागरी लिपी**: कोणतीही इंग्रजी अक्षरे न वापरता अस्सल संस्कृतीचा अनुभव.
- **मधोमध दुभंगणारे राजेशाही कवाड (Bisector Opening Screen)**: डावे व उजवे मोरपंखी रेशमी कवाड मध्यभागी जोडलेले असून त्यावर सुवर्ण जरीची बॉर्डर आहे.
- **डिजिटल सुवर्ण राजमुद्रा (Luxury Motion Seal Button)**: कवाडाच्या मध्यभागी २४ कॅरेट सोन्याचे चक्र, १२ कमळ पाकळ्यांचे फिरणारे सुवर्ण जाळीदार चक्र, बाप्पांचे नक्षीदार रेखाटन व लाल माणिक टिळक.
- **दोन्ही बाजूंची सजीव तोरणे (Animated Realistic Torans)**: पानाच्या डाव्या व उजव्या कडेला नारंगी-पिवळ्या झेंडूच्या फुलांच्या आणि हिरव्यागार आंब्याच्या पानांच्या उभ्या तोरण माळा, ज्या मंद झुळुकीवर नैसर्गिकपणे डोलतात.
- **गोड व लोभस बाल गणपती (Adorable Cute Bappa PNG)**: चौकोनी पार्श्वभूमीशिवाय (transparent isolated) राजेशाही आसनावर विराजमान झालेले, मोदक घेतलेले हसरे बाल गणपती आणि पाठीमागे संथ श्वास घेणारे सुवर्ण प्रभामंडळ (Breathing Divine Halo).
- **३ सेकंदांची नियंत्रित पुष्पवृष्टी (3-Second Flower Shower)**: दार उघडताना बरोबर ३ सेकंदांसाठी झेंडूच्या पाकळ्यांची मंगल पुष्पवृष्टी होते, त्यानंतर स्क्रीन स्वच्छ व वाचनीय राहते.
- **परस्परसंवादी अनुभव (Interactive Micro-Animations)**:
  - 🔔 Web Audio API द्वारे नैसर्गिक पितळी घंटेचा नाद.
  - 🪔 आरती समईची तेजोमय थरथरणारी ज्योत.
  - 🍛 केळीच्या पानावर गरमागरम उकडीचे मोदक व साजूक तुपाची धार.
  - 🗺️ दादर 'जोशी निवास' नकाशा व गुगल मॅप्स थेट दिशादर्शन.
  - 📅 **कॅलेंडरमध्ये जोडा**: १४ सप्टेंबर २०२६ साठी `.ics` आमंत्रण फाइल डाउनलोड.
  - 📲 **व्हॉट्सॲप / सोशल शेअर**: एका क्लिकवर आप्तेष्टांना मराठीत निमंत्रण पाठवण्याची सुविधा.
